Thresholds

Score = 0.5 + 2.5 × (positive similarity − negative similarity), clamped to 0–1. Defaults are heuristics, not calibrated values.

Anything below the questionable threshold is irrelevant.

          AI classification
          
      
          Layers run cheapest-first: your rules → built-in regex → local embeddings → (optional) web context → (optional) local LLM. The AI layers only run for pages the earlier layers could not decide, and never override your explicit rules. All inference is local.
          
      
      
      
      
          
        
        
        
      
          
      
          
        
        
        
        
      
          
      
          Verdicts below the minimum confidence, or without any usable evidence about the page, are downgraded to questionable. The in-browser runtime downloads weights from Hugging Face once (Firefox will ask for permission); Ollama/llama.cpp let you run Qwen3-0.6B or any other local model.

          Caches & feedback
          
      
          Local caches of final decisions, title embeddings, search results and LLM verdicts. Entries expire and are bounded; keys include the model version and your goal/thresholds/rules, so changing settings never reuses stale decisions. Feedback ("was this correct?") is stored locally only.
